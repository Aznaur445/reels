# Рилсы «Стройконтроля»

Продающие вертикальные ролики (1080×1920, 30 fps, до 60 с) для [stroy-control1.ru](https://stroy-control1.ru) на Remotion.
Основа каждого ролика — голос автора с диктофона. Голос не синтезируется и не заменяется: поверх него
накладываются субтитры, экраны сервиса, анимации и финальный призыв с кодовым словом.

## Как сделать ролик

```bash
npm install
npm run reel -- ~/Загрузки/запись.m4a --name сроки-срываются      # звук → расшифровка → монтаж → раскадровка
# смотрим videos/<id>/storyboard.md, правим edit.json / storyboard.json
npm run reel -- videos/<id>                                     # пересобрать после правок
npm run render -- <id>                                          # mp4 + обложка в videos/<id>/out/
# или напрямую: npx remotion render <id> out/<id>.mp4
npm run studio                                                  # предпросмотр в браузере
```

Подходят m4a, mp3, wav, ogg и видео (из видео берётся только звук).

### Что делает `npm run reel`

1. **Звук** (`scripts/lib/audio.mjs`, ffmpeg): срез низа и верха, шумоподавление `afftdn`, лёгкий компрессор,
   обрезка тишины в начале и в конце, двухпроходный `loudnorm` до −14 LUFS → `audio/clean.wav`. Исходник в `source/` не меняется.
2. **Расшифровка** (`scripts/transcribe.py`): faster-whisper `large-v3` (или `medium`, `WHISPER_MODEL` в `.env`), язык ru,
   тайминг каждого слова → `transcript.raw.json`. Если локальная модель недоступна, используется OpenAI API
   (`OPENAI_API_KEY` в `.env`). Если нет и ключа, расшифровку делает **GitHub Actions** («Расшифровка»): закоммитьте
   папку ролика, и через пару минут `transcript.raw.json` появится в той же ветке.
3. **Термины** (`scripts/lib/terms.mjs`): ГИП, АР, КР, ОВиК, ВК, ЭОМ, циклограмма, субподрядчик, Стройконтроль, Excel, Telegram → `transcript.json`.
4. **Монтаж** (`scripts/lib/edit.mjs`) → `edit.json`: слова-паразиты («э-э», «ну», «как бы», «типа»), повторы, оборванные слова;
   паузы длиннее 0,4 с сжимаются до 0,2 с; склейки с кроссфейдом 40 мс → `audio/voice.wav`.
   Сомнительные места помечены `"apply": false`: они не вырезаются, пока вы не скажете.
   Если речь вместе с финалом не помещается в 60 с, самые слабые фразы помечаются `"keep": false`.
   Если первые 2 секунды слабые, в `hook` предлагается фраза-вопрос или фраза-боль из вашей же речи.
5. **Раскадровка** (`scripts/lib/storyboard.mjs`) → `storyboard.json` и таблица `storyboard.md`.
   Визуал подбирается по смыслу слов:

| Вы говорите про… | В кадре |
|---|---|
| сроки, просрочки, этапы | `StageGraph`: схема этапов, просроченный этап загорается красным |
| задачи, подрядчиков, проверку | `TaskCard`: «На проверке» → «Принято» с галочкой |
| графики, проценты, циклограмму | `ScheduleBars`: растущие полосы / циклограмма |
| чаты, Excel, почту, хаос | `Chaos`: вихрь иконок собирается в один экран проекта |
| отчёты, напоминания, Telegram | `PhoneNotification`: телефон с уведомлением «Ежедневный отчёт» |
| биржу, заказы, отклики | `OrderFeed` и `ExecutorCard` (рейтинг, выбор исполнителя) |
| число, которое вы назвали | `Counter`: крупный счётчик (только ваши числа) |
| ключевые слова | `KineticWord`: слово вылетает крупно по центру |

Субтитры (`Subtitles`) идут по 2–4 слова, текущее слово подсвечено акцентным цветом.
Финал (`CtaKeyword`): «Напишите в комментариях слово ГРАФИК — пришлю бесплатный доступ», внизу stroy-control1.ru.
Если призыв прозвучал голосом, кодовое слово берётся из записи.

## Папка ролика `videos/<дата>-<название>/`

```
source/              исходник с диктофона (не меняется)
audio/clean.wav      после шумоподавления и выравнивания громкости
audio/voice.wav      после монтажа: это и звучит в ролике
transcript.raw.json  расшифровка Whisper с таймингом слов
transcript.json      с исправленными терминами
edit.json            что вырезано (можно править руками)
storyboard.json      раскадровка: из неё собирается ролик ("locked": true — не перезаписывать)
storyboard.md        текст, вырезанное и таблица раскадровки для согласования
post.md              подпись к посту и автоответ в директ
out/<id>.mp4, out/cover.png
```

## Формат `storyboard.json`

```jsonc
{
  "scenes": [{"type": "stageGraph", "from": 0.0, "to": 2.4, "props": {"overdueText": "Просрочен на 3 дня"}}],
  "kinetic": [{"text": "сроки", "at": 1.2, "duration": 0.9}],
  "cta": {"keyword": "ГРАФИК", "spoken": false, "from": 24.3, "duration": 6.5},
  "cover": {"title": "Подрядчик *сорвал срок*?"}   // *звёздочки* = акцентный цвет
}
```

Типы сцен: `stageGraph`, `taskCard`, `scheduleBars` (`mode: bars|cyclo`), `phoneNotification`, `orderFeed`,
`executorCard`, `chaos`, `counter` (`value`, `suffix`, `label`), `kineticWord` (`text`), `screenshot` (`src` из `public/screens`, `focus`, `zoom`).
Витрина всех компонентов: композиция `showcase` (`npm run showcase`).

## Стиль и безопасные зоны

Цвета и шрифт взяты с сайта: фон `#f6f1e6`, панели `#fffcf5`, текст `#2d2a24`, акцент `#8a6a3f`, мягкий акцент `#f1e7d4`,
«готово» `#4f8a5b`, «просрочено» `#c0563f`; шрифт Manrope с кириллицей (лежит в `public/fonts`, лицензия SIL OFL).
Всё важное находится между 250 px сверху и 400 px снизу, справа 150 px оставлены свободными (`src/theme.ts`).
Экраны продукта нарисованы компонентами на примерных данных («Поликлиника на Лесной, капремонт», ГИП Никитина Мария,
«ЭлектроПроект», «АкваПроект»). Скриншоты в `public/screens` взяты из `public/landing/design` репозитория stroykontrol (демо-данные).

## Музыка

`public/music/podlozhka.mp3` — подложка, сгенерированная кодом этого репозитория (`npm run music`,
`scripts/make_music.py`: аккорды, бас, перебор, мягкий ритм). Чужих сэмплов в ней нет, поэтому её можно использовать
в коммерческих целях без ограничений: лицензия CC0, автор — этот репозиторий.
Под голосом музыка автоматически опускается до −22 dB, в паузах и на финале поднимается до −15 dB (`Reel.tsx`, `useDucking`).
Если положите другой трек, укажите здесь источник и лицензию (например, YouTube Audio Library или Pixabay Music,
обе разрешают коммерческое использование) и поменяйте `music.src` в раскадровке.

## Облачная сессия Claude

В облаке закрыт доступ к HuggingFace, поэтому Whisper large-v3 запускается в GitHub Actions (`.github/workflows/transcribe.yml`).
Workflow `tts-test.yml` синтезирует речь из `tts.txt`. Он нужен только для проверки шаблона, в настоящих роликах звучит только ваш голос.
Ключи API хранятся только в `.env`, а он в `.gitignore`.
